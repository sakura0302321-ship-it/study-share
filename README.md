概要：

StudyShareは、受験勉強の学習時間やタスクを記録・管理するための学習管理アプリです。

受験予定日までの日数を確認しながら、日々の学習時間や科目を記録できます。また、学習時間を週間・月間のグラフで確認したり、勉強するタスクを管理したりすることができます。

Supabaseを利用してデータを保存しているため、学習記録やタスクを自動で同期できます。

主な機能：

受験予定日の管理

受験予定日を設定すると、受験日まであと何日かを自動で計算して表示します。

学習時間の記録

日付を選択して、以下の内容を記録できます。

* 学習時間
* 科目
* 学習した日付

記録した学習時間は後から確認・削除できます。

学習時間のグラフ表示

学習時間を週間または月間でグラフ表示できます。

日ごとの学習時間を棒グラフで確認できるため、学習量の変化を視覚的に確認できます。

タスク管理

今日・週間・月間の3種類に分けて学習タスクを登録できます。

タスクには以下の操作ができます。

* タスクの追加
* タスクの完了
* タスクの削除
* 完了したタスクへの共有メモの追加

データの自動同期

学習記録やタスクなどのデータはSupabaseに保存されます。

15秒ごとにデータを取得することで、最新のデータを自動的に反映する仕組みを実装しています

使用技術：

* HTML
* CSS
* JavaScript
* Vue.js 3
* Tailwind CSS
* Supabase

技術的なポイント：

Vue.jsのリアクティブなデータ管理を利用して、タスクや学習記録を画面にリアルタイムで反映しています。

computedを利用して、以下のような表示データを動的に計算しています。

* 受験日までの日数
* 選択した日付の学習記録
* 週間・月間の学習時間
* 表示するタスク

また、Supabaseのデータベースと連携し、学習データを保存・取得できるようにしています。

データ構成：

Supabaseのstudy_dataテーブルに学習データを保存しています。

保存している主なデータは以下の通りです。

* tasks
* logs
* examDate

tasksには学習タスク、logsには学習時間の記録、examDateには受験予定日を保存しています。

使い方：

1. 受験予定日を設定する
2. 学習するタスクを追加する
3. 勉強した時間と科目を記録する
4. 週間・月間のグラフから学習量を確認する
5. 完了したタスクに必要に応じてメモを残す

今後追加したい機能：

* ユーザーごとのアカウント管理
* ログイン・ログアウト機能
* 学習科目ごとの統計表示
* 学習時間の目標設定
* 月ごとの学習時間比較
* スマートフォン向けの操作性向上

制作目的：

学習塾でアルバイトをするにつれ、受験勉強では勉強した時間やタスクを継続的に管理することが重要だと考え、このアプリを制作しました。

単に学習時間を記録するだけではなく、受験日までの残り日数や学習時間のグラフ、タスク管理を一つの画面にまとめることで、毎日の学習状況を簡単に確認できるようにしました。
